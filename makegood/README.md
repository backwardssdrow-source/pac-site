# MakeGood Co. published website

This release publishes the approved edited-copy preview with compact footer buttons.
The 15 standalone HTML files, `site.css` and `site.js` are the current editable source.
The outlined `makegood-sunrise.svg` is unchanged.

The historical `.github/makegood-source.html` and multipage generator predate this approved release. Do not regenerate this website from them; update the standalone files instead.

Navigation and service filters are live. The contact form still creates an unsent local draft; email submission, booking and payments are not connected. This release does not collect form submissions. Existing `noindex,nofollow` settings are retained.
